# HU-03 — Exportación de reportes de asistencia a Excel

**Como** Presidente del Centro de Estudiantes  
**Quiero** exportar la asistencia de una actividad a un archivo `.xlsx`  
**Para** compartir los resultados oficiales o conservar un respaldo
institucional.

## Metadatos

- Prioridad: P1
- Valor de negocio: Alto
- Estimación inicial: 8 SP
- Dueño funcional: PO/SM
- Dueño técnico principal: Dev Data
- Colaboración: Dev Mobile (progreso, resultado y Share Intent)
- Dependencias: actividad con asistencias, Room, Apache POI y FileProvider

## Criterios de aceptación (Gherkin)

### Escenario 1: Generación y exportación de archivo Excel

- **Dado** que una actividad finalizó o tiene asistencias locales
- **Cuando** el usuario presiona `Exportar a Excel`
- **Entonces** se genera un `.xlsx` con los estudiantes, estado (`PRESENTE`,
  `TARDANZA`, `FALTA`, `JUSTIFICADO`), fecha y hora exacta de marcado

### Escenario 2: Compartir archivo directamente

- **Dado** que el `.xlsx` se generó correctamente en almacenamiento privado o
  en una ubicación elegida por el usuario
- **Cuando** termina el procesamiento
- **Entonces** se abre el selector nativo de Android para compartirlo por
  WhatsApp, correo u otra aplicación compatible, o guardarlo localmente

### Escenario 3: Error durante la exportación

- **Dado** que ocurre un error de escritura o no hay espacio disponible
- **Cuando** se intenta generar el libro
- **Entonces** no se comparte un archivo incompleto, se libera el recurso y se
  muestra un mensaje recuperable que permite reintentar

## Reglas de negocio

- El libro contiene una hoja `Asistencia` con estas columnas, en orden:
  `Apellido y nombre`, `Código de estudiante`, `DNI`,
  `correo institucional`, `Estado`, `Fecha`, `Hora`.
- La fecha usa `yyyy-MM-dd`; la hora usa `HH:mm:ss`; ambas se calculan en la
  zona horaria del dispositivo a partir del timestamp persistido.
- Los identificadores se escriben como texto para no perder ceros iniciales.
- Los estados exportables son `PRESENTE`, `TARDANZA`, `FALTA` y `JUSTIFICADO`.
- Las filas se ordenan por `Apellido y nombre` y luego por
  `Código de estudiante` para producir resultados deterministas.
- El archivo sugerido usa el patrón
  `asistencia_<actividad>_<yyyyMMdd_HHmmss>.xlsx`, con el nombre de actividad
  saneado.
- El URI compartido es `content://` mediante `FileProvider`, con permiso de
  lectura temporal y MIME
  `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`.
- Todo el flujo funciona en modo avión y la generación ocurre fuera del hilo
  principal.

## Evidencia para aceptación

- Libro abierto correctamente por una aplicación compatible.
- Verificación de encabezados, tipos de celda, orden, estados y timestamps.
- Share Intent con URI no expuesto como `file://`.
- Prueba de error que confirme que no queda un archivo parcial compartible.
